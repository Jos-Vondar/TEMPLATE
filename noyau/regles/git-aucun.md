## Sans git : tout reste sur ce poste

- **Ni dépôt, ni historique, ni sauvegarde ailleurs** ; un domaine est un dossier `travail/<NOM>/`.
  Perdre le poste perd tout, et une suppression ne se rattrape pas.
- **La clôture contrôle sans rien envoyer** : elle projette, contrôle ce qui a changé depuis la
  précédente et réécrit les empreintes de `.claudeos/`. Un levier `FORCE_…` qu'un contrôle propose
  se pose devant la commande de clôture que son message affiche.
